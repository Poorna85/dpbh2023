# Multi Word Finder Options

## Project Overview

Multi Word Finder Options is a web-based application built using AngularJS and Angular Material.  
This project allows users to create and manage collections of words dynamically.

Users can:
- Create collections
- Add multiple words
- Edit words
- Remove words
- Enable auto-search functionality
- Select collections from dropdown menus

The project provides a clean Material Design user interface for better user interaction.
